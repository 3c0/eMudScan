# Roadmap

What is planned for the next versions of eMudScan. Plans can change: the
[changelog](../CHANGELOG.md) lists what each version actually brings.

## After 2.0.0

Possible minor versions, in no fixed order:

- Python versions that only receive security fixes, for which python.org
  publishes no installer, updated with the builds of
  [adang1345/PythonWindows](https://github.com/adang1345/PythonWindows): only
  once you agree, with each download checked against a SHA-256 written into
  eMudScan, and with a warning that these builds do not come from python.org and
  that replacing the Python of a program may break it.
- A command-line scan for administrators, with a report file and an exit code.
- New checks and newly published fixed versions.

Version numbers are explained at the top of the [changelog](../CHANGELOG.md).
